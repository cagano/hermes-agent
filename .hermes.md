# hermes-agent

## Environment
```bash
source venv/bin/activate   # always first
```

## Key entry points
- `run_agent.py` — AIAgent class, `_build_system_prompt()`, `run_conversation()`
- `cli.py` — HermesCLI interactive loop
- `agent/prompt_builder.py` — system prompt assembly (identity, guidance, skills, context files)
- `toolsets.py` — toolset definitions, `_HERMES_CORE_TOOLS`
- `tools/registry.py` — central tool registry
- `hermes_state.py` — SQLite session store

## File dependency chain
```
tools/registry.py  ←  tools/*.py  ←  model_tools.py  ←  run_agent.py / cli.py
```

## Running / testing
```bash
python -m pytest tests/ -x -q          # full suite
python -m pytest tests/ -x -q -k name  # single test
python cli.py                           # interactive
```

## Customs / patches
- Local patches live in `~/.hermes/hermes-agent/` — preserve on `hermes update`
- Plugin: `~/.hermes/plugin.py`
- Config: `~/.hermes/config.yaml`, secrets: `~/.hermes/.env`

## Coding conventions
- Wrapper-first, minimal diffs
- Tools register via `registry.register()` at import time
- System prompt is built once per session and cached (`_cached_system_prompt`)
- Memory blocks from `MemoryStore.format_for_system_prompt()` — stable across turns
